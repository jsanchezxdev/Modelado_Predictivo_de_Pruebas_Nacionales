# Modelado_Predictivo_de_Pruebas_Nacionales
El presente proyecto tiene como objetivo: Desarrollar y evaluar modelos predictivos basados en algoritmos de Machine Learning y redes neuronales para estimar el desempeño académico en las Pruebas Nacionales de la República Dominicana, identificando patrones lineales y no lineales para analizar su posible relación con los resultados de PISA.
